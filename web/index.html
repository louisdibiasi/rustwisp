Server

This page is served over HTTPS, so the browser will refuse a plain ws:// address. Use wss://, or ws://localhost for a server on this machine.

This server address came from a link. Only connect with a login if you trust it.

Only sent if the server asks for a login. The password is never saved or put in a link.

The server relays a plain http:// request. This page cannot do TLS itself.

Line endings are sent as CRLF.
